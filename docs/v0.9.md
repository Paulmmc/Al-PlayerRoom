## 1. 放大时的填充

三处都在 `src/pages/home/index.vue`。颜色仍按现在的来源，只改放大这一段的画法。

| 位置 | 原色 |
|------|------|
| 平台标签 | `tabActiveBg` |
| 状态筛选 | 「全部」用 `accent`，其余用 `STATUS_COLORS` |
| 大图标 / 列表 | 现在的胶囊滑块色 |

静止时用这个原色的实色铺满滑块，透明度是 1。按住放大期间不要给滑块元素设 `opacity`。把原色拆成 `r, g, b`，填充写成 `rgba(r, g, b, 0.78)`，从下到上两层：

1. 轨道的轻度模糊。H5 用 `backdrop-filter: blur(4rpx) saturate(1.5)`。模糊只取轨道，不把字模糊进滑块。饱和度提高后，透出来的灰不会把色相冲掉。
2. `rgba(r, g, b, 0.78)` 盖在模糊上。大约两成是轨道，八成仍是原来的红、状态色、白或深灰。

滑块上沿加一条白色渐变，高度约占滑块的 30%，透明度从 0.35 收到 0。这条渐变和文字都不参与 0.78。

微信小程序没有 `backdrop-filter` 时，省掉模糊和上沿渐变，`rgba(r, g, b, 0.78)` 必须留下。

放大后的填充叠在文字下面。字的颜色和字重仍按现在的选中规则，透明度保持 1。松手、滑块缩回后，填充回到透明度 1 的实色，上沿渐变去掉。点未选中项时滑块不放大，填充也不变薄。

## 顺序

1. 放大期间的填充改成 `rgba(r, g, b, 0.78)`，不要用元素 `opacity`，填充放到文字下面。
2. H5 补上轨道模糊（饱和度 1.5）和上沿渐变。
3. 按验收走 H5。微信小程序确认放大时原色还在，字仍然清楚。
