# PlayerRoom 开发记录

玩家自己的多平台游戏库（Switch / PS5 / Steam）。无后端。已落地的都记在本文，当前行为以本文为准。给其他 AI 的约定见 [协作.md](./协作.md)。`开发文档.md`、`下一版.md`、`v0.3.md` 到 `v0.14.md`，以及 `v0.16.md` 都已做完，不要再按那几份实现。`v0.15.md` 的公共主题和底部导航配色还没做。

本地：`npm run dev:h5`（http://localhost:5173/），微信小程序 `npm run build:mp-weixin`。

## 现在代码在哪

- 页面：`src/pages/home`（平台 Tab + 状态筛选 + 三平台货架 + 添加）、`search`（卡片列表）、`game/detail`（备注下是手账，没有截图横滑）、`game/edit`、`player/profile`
- 货架：首页上面是当前平台已上架的 `PackShelf`，最多 8 本，不受状态筛选影响。下面的游戏列表包含这个平台里符合筛选的全部游戏，已经在书架上的也留在列表里。平台标签、状态筛选、「大图标 / 列表」都是按住滑块会放大并跟手的分段，松手才切换。静止滑块是实色；按住放大时原色写成 `rgba` 0.78，字仍不透明，H5 再轻度模糊轨道。拖动过程中滑块颜色按当前位置在相邻两项的原色之间混合，松手再过渡到落下的那一项。没有上沿白渐变。列表区域不再左右滑切换版式。默认列表。列表每一行是一条封面，左边是画面，从大约 18% 慢慢淡到 78% 的页面底色。书脊顶端是一枚白色状态图标，没有色条。焦点条是游戏名、强调色状态图标、强调色小书架和「删除」。列表名字在文字区垂直居中，右下角两枚小图标都是强调色。大图标封面右上角同样是两枚强调色图标。这些小图标只进入详情。详情用滑块改游玩状态和上架/下架，编辑页仍用下拉菜单。Switch 浅灰白底配任天堂红，PS5 近黑蓝配电光蓝，Steam 深蓝配浅蓝，颜色在 `src/theme/store.ts`。排期、我的、详情、编辑和搜索都跟着游戏库当前平台换色。首页状态筛选的滑块同色，「全部」是字，另外四项是小图标加文字。未选中的状态图标用强调色，选中的落在滑块上时用滑块字色。「我的」的状态图标用游戏库当前平台的强调色。没有浅色横条。左上角按钮点开是游戏库、排期、我的，底部不再常驻这三项。排期页按天列出准备玩的游戏，今天在前，过去单独放在「之前的安排」。新增可以选单日或连续日期，一次最多 366 天，不再按每款 30 条截断。搜索页还在工程里，这一版没有入口。详情手账是左侧时间轴、右侧卡片，长按约 0.5 秒才出现编辑和删除。
- 数据只走 `src/services/catalog.ts`。读盘、玩家库数组在 `game-store.ts`，手账在 `journal.ts`，排期在 `plans.ts`，入库前的整理在 `normalize.ts`。页面不要绕过 `catalog.ts` 直接写库。玩家库 key 是 `playerroom.games`；种子 6 款在 `src/data/catalog.ts`；资料库三平台各 15 款在 `src/data/game-catalog.ts`
- `Game.status` 为 `backlog | playing | done | shelved`（想玩 / 在玩 / 已通关 / 搁置）。另有 `note`（最多 40 字）、`journal`（最多 30 条）和 `onShelf` / `shelfAt`（是否在书架、越大越靠前）。没有 `screenshots`。首页状态筛选只筛下面的列表。手账走 `addJournalEntry` / `updateJournalEntry` / `removeJournalEntry`，上下架走 `setOnShelf` / `listShelfGames`。从「我的」跳回首页的筛选意图在 `src/services/home-intent.ts`，不进 storage
- 资料库封面都在自己的目录：Switch / PS5 是 `cover.jpg`，Steam 是 `capsule.jpg`。不再循环种子图
- 用户固定 `p-me`
- 货架 3D 以 H5 为准；小程序走 `CasePack` 里 `#ifdef MP` 的 2.5D

玩家库和资料库是两套东西。资料库只在添加页按当前平台点选，保存才 `addGame` 进玩家库。`removeGame` 只删玩家库。

## 已落地

1. **uni-app 骨架。** Vue 3 + Vite + TS。首页、搜索、详情、玩家页，先用本地假数据。
2. **多平台库。** `platform` 为 `switch | ps5 | steam`。首页分段。当时「我的」按平台分组列卡片，第 13 条改成四个状态的计数。示例换成能认出的游戏名。
3. **单一用户、可编辑。** 收成 `p-me`。可改标题、介绍、平台、封面，用 `uni` 本地存储。
4. **三套商店皮 + 真图。** eShop / PS Store / Steam 主题在 `src/theme/store.ts`。封面放 `src/static/games/`。当时用 `screenshots[]` 替代纯色截图条，第 16 条拿掉这个字段，详情改成手账。
5. **添加与删除。** `addGame` / `removeGame`。首页 FAB，编辑页 `mode=create`。列表切换、卡片入场、详情淡入。
6. **改名修过一次。** 表单必须 `v-model`，`:value` + `@input` 会改了却不保存。读取经 `unwrapStorage`，兼容 H5 的 `{ type, data }`。页面显示前 `reloadFromStorage()`。
7. **书本式货架。** 先在设计稿里定 Switch 红脊卡带盒、PS5 透蓝光盘盒（实物约 105×170×11、135×170×15：封面 + 书脊 + 页边 + 顶边）。随后落到 `PackShelf` / `CasePack`。当时 Steam 仍是胶囊列表，第 15 条改成深色游戏盒。封面用项目内图，不是官方盒扫。
8. **货架手感。** 盒面约 160×258（Switch）/ 176×222（PS5），过渡约 0.5s。拖动跟手（`dragX` / `--nudge`），松手再吸附。高度贴盒，去掉上方大块留白。邻盒侧转，焦点前推。
9. **资料库与玩家库分开。** `listCatalogByPlatform`。`game-catalog.ts` 里 Switch、PS5、Steam 各 15 款真实游戏名。点选只预填，标题和封面仍可改。新 id 为 `g-user-${Date.now()}`。
10. **删除入口补齐。** 当时货架焦点条、Steam 行、搜索、我的、详情都能删。第 13 条拿掉「我的」的删除；第 15 条起 Steam 也走货架焦点条，不再是列表行。确认文案说明资料库还在。首页删除用 `refresh(false)`，不把货架焦点打回第一本。删除色跟平台主题。`StoreGameCard` 只有 `removable` 时才显示删除。
11. **去掉测试种子，封面不串平台。** 玩家初始库去掉 `g-test-*`，`mergeWithSeed` 丢弃本地残留。当时资料库封面按本平台 cover + shot 循环，不借别的平台的图。Switch / PS5 的循环在第 12 条换成各自封面；Steam 的循环在第 14 条换成各自 `capsule.jpg`。资料库条目当时 `screenshots` 为空，第 16 条起游戏上不再有这个字段。添加页切换平台时，选中项若不在新平台资料库，清空标题、介绍、封面、标签。当时还会清截图。状态不清；第 13 条起备注也不清。

设计线框（游戏库 / 详情 / 编辑 / 搜索）在货架落地后已从仓库删掉，比例和结构以 `CasePack.vue`、`PackShelf.vue` 为准。

12. **资料库自己的封面 + 游玩状态。** 按 `开发文档.md` 做完，盒子比例和 Steam 胶囊列表没改。

- 30 张竖版 JPG 在 `db-sw-01`–`db-sw-15`、`db-ps-01`–`db-ps-15` 的 `cover.jpg`（短边 720）。是项目内绘制的封面，不是官方盒扫，也不同于 6 款种子的封面、胶囊和截图。当时还没有 `db-st-*` 封面，第 14 条补上。
- `toGame`：Switch / PS5 固定 `/static/games/${id}/cover.jpg`。`PLATFORM_COVERS` 已删。当时 Steam 仍留 `STEAM_COVERS` 循环种子图，第 14 条删掉并改成各自 `capsule.jpg`。资料库条目的 `status` 写成 `backlog`，点选不抄进表单。
- 类型和颜色在 `src/types/catalog.ts`。顺序是在玩、想玩、已通关、搁置。颜色：想玩 `#8b9cff`、在玩 `#3DDC97`、已通关 `#E8B84A`、搁置 `#6b7388`，不跟平台主题走。
- 种子：塞尔达、法环 `playing`；奥德赛、空洞骑士 `done`；战神 `backlog`；黑神话 `shelved`。新游戏不传状态时是想玩。
- 读档走 `normalizeGame`。状态已是四态就留；种子缺状态用种子上的，其余用想玩。封面：相册图（`data:` / `blob:` / `wxfile:` / `file:`）和自己 id 目录下的图保持；标题去掉首尾空格后，能对上同一平台的 Switch / PS5 资料库，就改成那条 `cover.jpg`；对不上的保持。当时 Steam 仍可指向黑神话或空洞骑士，第 14 条起对得上 Steam 资料库的会改成自己的 `capsule.jpg`。「艾尔登法环」不会因为标题相同从 PS5 种子改到 Steam 资料库。玩家改过标题的封面不动。
- `mergeWithSeed` 的种子分支：存储里的状态已是四态就留玩家的，否则用种子的。`addGame` 会再走一遍封面规则。`updateGame` 遇到非法 `status` 就忽略。仍只写 `playerroom.games`。
- 首页平台 Tab 下有「全部」和四个状态。默认全部，切平台保留筛选，筛选不进 storage。筛选变化走 `refresh(true)`，货架从新列表第一本算起；删除仍是 `refresh(false)`。平台没有游戏时文案是「该平台暂无游戏」；有游戏但筛空时是「这个平台还没有在玩的游戏」。添加链接不带状态。停在「在玩」时添加，新游戏是想玩，回来后不会出现在「在玩」里。
- 当时货架焦点条是「平台 · 状态 · 标签」，只有焦点盒封面右上角有约 8px 的状态点。第 13 条换成书脊色条和标题旁色标；第 14 条又在封面左上角加了状态文字。
- 编辑页的状态在介绍和平台之间，新建默认想玩，编辑读当前游戏。详情里点一下就 `updateGame`，用返回值刷新当前页。
- 这一版没做：备注、评分、时长、价格；「我的」改成状态计数或放进底部导航；搜索页再做一套筛选；Steam 3D 货架和盒体改动；给 Steam 再做 15 张独立封面。备注、「我的」计数和搜索筛选在第 13 条。
