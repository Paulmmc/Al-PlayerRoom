## 不要互相踩

- 改库只走 `src/services/catalog.ts`。页面不要直接写 `playerroom.games`。
- 表单用 `v-model`。`:value` + `@input` 会改了却不保存。
- 读盘走 `reloadFromStorage()` / `unwrapStorage`。uni H5 可能把存储包成 `{ type, data }`。
- 删除只调 `removeGame`，资料库文件不动。确认文案说明资料库还在。
- 首页删除用 `refresh(false)`，不要让货架焦点回到第一本。筛选变化才用 `refresh(true)`。
- 封面不跨平台。Switch / PS5 资料库用自己的 `cover.jpg`，Steam 用自己的 `capsule.jpg`。相册图（`data:` / `blob:` / `wxfile:` / `file:`）和自己 id 目录下的图保持。
- 不要把 `g-test-*` 加回种子。`mergeWithSeed` 会丢掉这类 id。
- 货架外观以 `CasePack.vue`、`PackShelf.vue` 为准。仓库里没有设计稿。
- 小程序货架保持 `CasePack` 里现有的 `#ifdef MP` 回退。
- `v0.16.md` 已落地：排期可以单日或连续日期，一次最多 366 天，不再截成每款 30 条。不要再加选游戏搜索、平台筛选、月历或范围整体改期。`v0.15.md` 的公共主题和底部导航配色还没做，做的时候只改配色。v0.14 及更早也不要再做一遍。
