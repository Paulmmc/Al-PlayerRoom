# v0.15 · 公共主题与底部导航配色

**状态：历史方案，已被后续实现取代。** 本文的固定公共蓝色主题与底部导航方案未按原规格落地。当前代码已采用左上角菜单，以及各页面跟随游戏库当前平台主题的方式，见 [开发记录.md](./开发记录.md) 第 27～29 条，协作约束见 [协作.md](./协作.md)。本文保留当时的规格与验收清单供追溯，不再作为待实现任务或当前验收依据。

## 目标和范围

公共页面采用「主机控制中心」方向：深黑蓝背景、清晰白字和电光蓝强调，让游戏封面、当天安排及玩家现有数据成为重点。游戏库继续保留 Switch 红白、PS5 近黑蓝、Steam 深蓝三套主题，以及切换平台时整套换色的行为。

本版仅调整颜色及现有内容的颜色层次。布局、字体、组件造型、图标和操作严格沿用现有实现，不新增页面或功能。此前三屏预览图只作为配色和层次参考，不作为像素级设计稿；其中生成的状态标签、图标形状、封面、文字与现有实现不同的地方不照搬。

## 公共配色

| 用途 | 色值 | 使用位置 |
|---|---|---|
| 页面背景 | `#0C1017` | 排期、「我的」和对应公共页面顶部导航 |
| 底部导航背景 | `#090D14` | 三个 tab 共用，保持固定深色 |
| 卡片背景 | `#171F2C` | 排期卡片、页内表单、玩家统计卡片 |
| 控件轨道 | `#222E40` | 公共页筛选与选择区域 |
| 主文字 | `#F2F5FA` | 标题、游戏名、主要日期和数量 |
| 次要文字 | `#96A3B8` | 平台名、简介、辅助日期、空状态和未选中导航 |
| 公共强调色 | `#339DFF` | 筛选滑块、添加、保存、文字操作、公共页面选中导航 |
| 实色强调背景上的文字 | `#07111E` | 选中滑块及实色强调按钮内的文字和图标 |

按语义统一定义公共主题并供相关页面读取，避免各页散落一套新硬编码。三平台主题继续由 `src/theme/store.ts` 管理；公共主题与平台主题分开使用，不将当前平台背景应用到排期或「我的」。

## 底部导航规则

仍为「游戏库」「排期」「我的」三项。背景固定 `#090D14`，未选中图标和文字固定 `#96A3B8`，选中图标和文字使用相同颜色。

| 当前页面 / 状态 | 当前选中项颜色 |
|---|---|
| 游戏库 · Switch | `#E60012` |
| 游戏库 · PS5 | `#0070E0` |
| 游戏库 · Steam | `#66C0F4` |
| 排期 | `#339DFF` |
| 我的 | `#339DFF` |

首页提交平台切换时，底栏选中色与页面主题同时更新；拖动尚未提交时沿用现有提交时机，不提前改变平台。进入排期或「我的」后立即恢复公共电光蓝，不继承刚才的平台色。返回游戏库时使用首页当前实际选中的平台色，包括从「我的」带状态筛选返回的路径。冷启动也应正确初始化，避免先出现旧紫色再跳色。

保持现有 tabBar 的图标形状、大小、布局、高度、安全区和跳转方式。优先沿用 uni-app 原生 tabBar 能力，更新样式及现有图标的颜色资源；不要为了动态着色重写自定义导航。检查普通态和选中态图标，不能只更新文字颜色而让图片仍显示旧紫色。H5 与微信小程序均须验证。颜色跟随页面状态，不新增持久化 key 或主题设置。

## 排期页

- 页面、卡片、表单、筛选轨道和 FAB 使用公共配色。顶部导航白字，背景为公共页面底色。
- 今天的日期和时间轴点使用公共强调色；其他日期用次要文字色，未来日期点及连接线保持弱化的现有层次，不让整条时间轴抢过封面。
- 游戏名保持主文字色，平台名与辅助说明用次要文字色。过去未玩的提示保持低调，不改成警报红。
- 「玩过了」「改期」「移到今天」、保存等可操作文字使用公共强调色；删除沿用现有危险操作语义，不一并改蓝。
- 保留全部/未游玩/已游玩的现有滑块，按住放大时继续使用当前强调色的 `rgba` 0.78，文字不透明，拖动和提交规则不变。
- 保留日期分组、卡片尺寸、长按删除、页内新增/改期和展开后滚动行为，不重新排版。

## 我的

页面与统计卡片采用公共背景和卡片色，昵称及数量用主文字色，简介及游戏总数说明用次要文字色。公共状态图标使用电光蓝，保留当前图标加数量的四行结构，不根据预览图添加状态文字。

头像保留现有玩家头像或字母回退逻辑。默认头像强调色可跟随公共主题；若存在明确由玩家设置的个性化强调色则保留，不改写玩家资料或存储。公共状态图标的蓝色不要求修改玩家数据中的 accent。

不在本版增加「最近在玩」、成就、奖杯、等级、经验或游玩时长。此前讨论的玩家档案扩展仅作为后续方向。

## 其他页面及限制

- 搜索页虽然暂时没有导航入口，公共背景、卡片、筛选和文字使用同一套公共主题，保留原有功能与无入口状态；卡片中明确使用游戏平台主题的部分仍保持平台语义。
- 游戏详情、编辑/添加页和详情里的安排游玩表单继续使用对应平台主题，不强制改成公共蓝色。
- 不改变三平台书架、封面和盒体材质，不添加光晕、电竞花纹、装饰渐变、玻璃效果或新描边风格。
- 不改组件圆角、字号、间距、阴影、动画时长、分段控件手感、FAB 动效和长按规则。
- 不改数据结构、存储 key、游戏状态、手账及排期规则，不恢复搜索入口。
