## 2. 手账数据

在 `src/types/catalog.ts` 增加：

```ts
export interface JournalEntry {
  id: string
  /** 当天 0 点的本地时间戳 */
  at: number
  /** 去掉首尾空格后最多 200 字 */
  text: string
  /** 空字符串表示没有图。相册图规则与封面相同 */
  image: string
}
```

`Game` 增加 `journal: JournalEntry[]`。`AddGameInput` 不接收 `journal`，新建游戏是空数组。

`normalizeJournal`：

- 缺字段或不是数组：`[]`。
- 丢掉没有 `id`、以及正文和图片都空的条目。
- `text` 做 `trim` 后截到 200 字。`image` 不是字符串则写成 `''`。
- `at` 不是有限数字则用读取时的当前时间。
- 按 `at` 从新到旧排序。同一天多条保持这个顺序。
- 最多留 30 条，多出来的从最旧的丢。

手账属于玩家。`mergeWithSeed` 的种子分支：存储里已有 `journal`（含空数组）就留玩家的，缺字段才用种子的 `[]`。六款种子都写 `journal: []`。

仍只写 `playerroom.games`。`loadGames()` 后面现有的 `persist()` 会把去掉截图、补上手账的结果写回。

只从 `src/services/catalog.ts` 导出这三个函数，页面不要自己拼数组再整份 `updateGame`：

| 函数 | 作用 |
|------|------|
| `addJournalEntry(gameId, input)` | `input` 为 `{ at, text, image? }`。生成 `id = j-${Date.now()}`。整理后插到数组里，再按上面的规则规范化并 `persist`。游戏不存在返回 `undefined` |
| `updateJournalEntry(gameId, entryId, patch)` | `patch` 可含 `at`、`text`、`image`。找不到条目返回 `undefined` |
| `removeJournalEntry(gameId, entryId)` | 删掉这一条。找不到返回 `false` |

正文和图片都空时，添加和更新都拒绝，不写入。

`searchMyGames` 的匹配串加上各条 `journal.text`。标题、介绍、标签、平台名、备注的匹配不变。

## 3. 详情页

`src/pages/game/detail.vue` 在备注下面、编辑按钮上面加「手账」。这一块始终显示。

没有条目时，一句「还没有记录」和一个「记一笔」。

有条目时，新的在上面。每条显示日期 `YYYY-MM-DD`、正文；`image` 非空时在文字下面显示一张图，`mode="aspectFill"`。每条有「改」和「删除」。删除先 `uni.showModal` 确认，确认后 `removeJournalEntry`。

「记一笔」和「改」用同一块表单，不要新开页面：

- 日期：默认今天。用日期选择，存当天本地 0 点的时间戳。
- 正文：`textarea`，`v-model`，`maxlength="200"`，placeholder「写今天玩到哪了」。
- 图片：可选。点一下 `uni.chooseImage`，`count: 1`，`sizeType: ['compressed']`。H5 转 dataURL 再写入，其它端用临时路径，和编辑页封面一样。已有图时可以换，也可以清掉。
- 「保存」调用添加或更新，成功后收起表单并刷新当前游戏。正文和图片都空时提示「写一句或贴一张图」，不提交。
- 「取消」收起表单，不写盘。

40 字备注的输入框、失焦保存、状态切换、编辑和删除游戏都保持现在的行为。

货架、搜索卡片、添加页不展示手账。
