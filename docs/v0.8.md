## 2. 按住放大，跟随拖动

手势只认这三处控件本身。书架、游戏列表区域、另一处分段都不跟着动。

- 按住当前选中的滑块，滑块放大：宽加 48rpx，高加 32rpx，鼓出轨道，带很轻的阴影。放大小程序阴影看不清时，靠滑块比轨道更亮来分开。放大和缩回用约 0.25 秒、没有回弹的弹簧。
- 按住之后左右拖，放大的滑块跟着手指，停在第一项和最后一项之间。只有横向位移明显大于纵向，才算在拖滑块，页面仍可上下滚。
- 拖动时，字的选中样式跟着手指下的那一项。书架、列表和「大图标 / 列表」的数据在松手后才换。松手时手指还在原来的项，不刷新。
- 松手后滑块缩回，落到手指下的那一项。没过相邻两项的中线就弹回。快甩不按速度预判，只看松手时停在哪。
- 点未选中的字，当前滑块不放大，约 0.25 秒滑到那一项，然后按上一条更新书架或列表。
- H5 用鼠标点击时不放大，点哪项就切到哪项。触屏（H5 和小程序）按住才放大。

平台切到另一项时仍 `refresh(true)`。状态切到另一项时仍 `refresh(true)`。列表模式只改版式，不重新拉数据。

## 顺序

1. 三处分段改成同一套按住放大、跟手、松手落下。
2. 去掉游戏列表区域左右滑切换「大图标 / 列表」。
3. 按验收走 H5 的触屏和鼠标。微信小程序确认按住能放大，并且一行仍排得下 5 个状态和 3 个大图标。
